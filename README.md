## 🌟 About the Project / Төслийн тухай
**Travel Map MN** is a comprehensive interactive platform featuring over **1,659** scenic spots, historical sites, and tourist camps across Mongolia. Designed for both domestic and international travelers, it provides seamless navigation in **6 languages**.

Монгол орны байгаль, түүх, соёлын дурсгалт газрууд болон амралт, жуулчны баазуудыг нэгтгэсэн интерактив мэдээллийн сан юм. Нийт **1,659** объектыг багтаасан.

## ✨ Key Features / Гол онцлогууд

* 🔍 **Smart Search:** Search effortlessly in Mongolian & English.
* 📍 **1,659+ POIs:** Detailed database of resorts, landmarks, and transport hubs.
* 🌍 **Multilingual:** Supports 🇲🇳, 🇺🇸, 🇰🇷, 🇯🇵, 🇨🇳, 🇷🇺.

* 🎬 **Video Guide:** Built-in tutorial for seamless user experience.

## 📲 Installation Guide / Суулгах заавар

### 🍎 For iPhone / iOS (Safari)
1. Open [Travel Map MN](https://mongoliamapguide.github.io/map/) in Safari.
2. Tap the **"Share"** button (square with an upward arrow).
3. Scroll down and select **"Add to Home Screen"**.
4. Tap **"Add"**.

### 🤖 For Android (Chrome)
1. Open [Travel Map MN](https://mongoliamapguide.github.io/map/) in Chrome.
2. Tap the **three dots (⋮)** in the top right.
3. Select **"Install app"** or **"Add to Home screen"**.
